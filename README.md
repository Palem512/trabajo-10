## 🎯 Objetivo

Este trabajo práctico tiene como finalidad introducir a los estudiantes en los fundamentos del lenguaje **JavaScript**, mediante ejercicios prácticos organizados en archivos separados.

Se trabajará con:

* Variables (`var`, `let`, `const`)
* Tipos de datos
* If / else / else if
* Bucles
* Funciones con parámetros y retorno
* Arrays y objetos
* Clases y creación de instancias

## 🧩 Descripción de cada archivo

### **1. hola_mundo.js**

Imprime en consola el mensaje **"Hola JavaScript"**.

### **2. variables.js**

* Declaración de variables usando `var`, `let` y `const`.
* Explicación mediante comentarios.
* Práctica con tipos de datos: `string`, `number`, `boolean`, `null`, `undefined`.

### **3. control_flujo.js**

* Programa para determinar si un número es **par o impar**.
* Clasificación de una edad como **Niño / Adolescente / Adulto** empleando `if / else if`.

### **4. funciones.js**

* Función que calcula el área de un círculo.
* Función que suma los elementos de un array.

### **5. estructuras.js**

* Creación de un array de lenguajes de programación.
* Recorrido con `forEach`.
* Creación de un objeto usuario con propiedades: **nombre**, **edad**, **email**.

### **6. clases.js**

* Definición de la clase **Persona**.
* Implementación del método `saludar()`.
* Creación de una instancia y ejecución del método.

---

## ▶️ ¿Cómo ejecutar los scripts?

Asegurarse de tener instalado **Node.js**.

Luego, desde una terminal, ejecutar:

```bash
node nombre_del_archivo.js
```

Ejemplo:

```bash
node hola_mundo.js
```
